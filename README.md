# MBA COLLEGE WEBSITE – PREMIUM DEMO WEBSITE

A complete, multi-page, static website demonstration built for an MBA college in India. Designed to showcase professional website development capabilities to prospective educational institutions while adhering strictly to generic academic terminology and zero real or fictional brand identities.

---

## 1. Strict Technology Stack
- **HTML5** (Semantic structure across 7 pages)
- **CSS3** (Custom properties, responsive grid/flexbox layouts, smooth animations)
- **Vanilla JavaScript** (Zero external frameworks, libraries, or backend dependencies)
- **Hostinger Static Hosting Ready** (Runs directly in the browser)
